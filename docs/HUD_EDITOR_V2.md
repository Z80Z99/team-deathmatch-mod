# HUD 编辑器 V2

## 背景/全局

“背景/全局”现在也是完整的 HUD 场景。添加到这里面的组件会同时渲染在比赛、匹配和房间场景中，只有组件自身的触发条件才会改变显示状态。

## 滚动

常规页面、列表、房间成员列和 HUD 编辑面板的右侧滚动条均支持：

- 鼠标滚轮。
- 点击轨道跳转。
- 拖动滑块。

HUD 编辑器中的【组件】【属性】按钮固定在面板顶部，不参与内容滚动。

## 动效

- 进度条支持“填充”和“消耗”方向。
- 进度数值支持平滑过渡。
- 文字和进度标签支持内容变化时的淡入、滑入和缩放。
- 组件显示条件仍保留原有的出现 / 消失动画。

## 数据源筛选

数据源选择改为三级筛选：

1. 一级：指标，例如得分、击杀数、伤害、时间、金钱。
2. 二级：范围，例如本轮、整场、倒计时、状态。
3. 三级：对象，例如 A队、B队、我方、敌方、自己。

筛选后进入具体数据接口列表。文字组件的“+参数”使用相同的三级筛选方式。
